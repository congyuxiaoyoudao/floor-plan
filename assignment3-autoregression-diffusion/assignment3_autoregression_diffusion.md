# 任务3：自回归与Diffusion架构

## 概述
假设已知点的数量，多边形外轮廓，其他房间的多边形，要求网络推理得到剩下一个多边形。

## 两种生成方案

### 1. 自回归（Autoregressive）
```
[已知多边形] → [num_count] → [逐点生成] → [完整多边形]
```

- 按点的顺序逐个生成
- 每次生成依赖前面已生成的点
- 序列化生成过程

### 2. Diffusion（扩散模型）
```
[高斯采样点] → [去噪网络] → [前向反向公式] → [目标多边形]
```

- 从噪声逐步去噪
- 并行生成所有点
- 基于扩散过程的生成

## 对比分析

| 特性 | 自回归 | Diffusion |
|------|--------|-----------|
| 生成方式 | 序列逐点 | 并行去噪 |
| 速度 | 较慢 | 较快 |
| 质量控制 | 依赖顺序 | 全局优化 |
| 实现复杂度 | 中等 | 较高 |

## 输入条件

- `num_count`：目标多边形点数
- 已知外轮廓多边形
- 其他房间的多边形
- 空间约束条件

## 输出目标

生成满足条件的新多边形，需要：
- 符合点数要求
- 不与现有多边形冲突
- 符合外轮廓约束
- 拓扑结构合理
