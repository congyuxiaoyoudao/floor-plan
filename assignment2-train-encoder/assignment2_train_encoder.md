# 任务2：训练编码器

## 概述
假设已知点的数量，要求压缩房间、户型表达。能够给定多边形，编码为中间特征，也可根据中间特征，转为显式多边形。

**核心思想**：虚线框代表默认从固定初始化一个值，由网络自行推理出最终的特征。

## 要求

### (1) 利用自注意力机制，得到房间、户型级别的 Token 特征

能解码出对应的房间或户型。

- **黄色框**：代表房间的点 Token
- **绿色框**：代表房间户型 Token
- **要求**：用相同的点的矩阵，利用 Tensor 形状变化，实现下面的两种自注意力机制（torch 内的）

### (2) 利用 AE 框架，训练该网络，得到编码器、解码器、中间特征

上面绿色框作对应的输出，即为房间、户型级别特征，搭配上固定值初始化的点特征，解码出房间、户型。

## 架构类型

### 1. 房间级别自注意力编码
```
[房间点Token序列] → [自注意力层] → [房间级别特征]
```

### 2. 户型级别自注意力编码
```
[户型点Token序列] → [自注意力层] → [户型级别特征]
```

### 3. 房间级别自注意力解码
```
[房间特征 + 初始点Token] → [自注意力解码] → [房间多边形]
```

### 4. 户型级别自注意力解码
```
[户型特征 + 初始点Token] → [自注意力解码] → [户型多边形]
```

## 关键技术点

- 自注意力机制实现（基于 torch）
- Tensor 形状变换技巧
- AE（自编码器）框架
- 固定值初始化策略
- 编码器/解码器对称设计
